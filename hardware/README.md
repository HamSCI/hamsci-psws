PSWS hardware design files live in the instrument repositories, for example [PSWS-Magnetometer](https://github.com/HamSCI/PSWS-Magnetometer), [VLF-WC](https://github.com/HamSCI/VLF-WC), and [THRUHole-Grape](https://github.com/HamSCI/THRUHole-Grape).

Put working-group hardware that has no other home in this folder: editable source files (board layouts, 3D printing files), not just manufacturing outputs.
