## Code and design files

- [PSWS_Documentation](https://github.com/HamSCI/PSWS_Documentation): documentation for the PSWS project
- [PSWS-Magnetometer](https://github.com/HamSCI/PSWS-Magnetometer): magnetometer software and design files
- [VLF-WC](https://github.com/HamSCI/VLF-WC): the VLF whistler catcher receiver
- [THRUHole-Grape](https://github.com/HamSCI/THRUHole-Grape): the through-hole Grape receiver
- [ka9q-radio](https://github.com/HamSCI/ka9q-radio): the multichannel SDR software used by the HF receiver
